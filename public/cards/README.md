# Card images

17 WebP files generated by Nano Banana, optimized via cwebp (q82).

## Files (17 total, ~2.5 MB)

Faces (16):
- `ace-spades.webp` / `ace-hearts.webp` / `ace-diamonds.webp` / `ace-clubs.webp`
- `jack-*.webp`, `queen-*.webp`, `king-*.webp` for each suit

Back (1):
- `back.webp`

## Regenerating

See `scripts/README.md`. To regenerate:
```bash
npm run card -- <name> "<prompt>"
```
Output is PNG; convert to WebP with:
```bash
cwebp -q 82 -m 6 public/cards/<name>.png -o public/cards/<name>.webp
rm public/cards/<name>.png
```

## Notes

- Numbered cards 2–10 stay CSS-rendered (no images needed).
- Missing image → graceful fallback to CSS card.
